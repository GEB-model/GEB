# Configuration

The configuration of the GEB model is defined using a YAML file (commonly `model.yml`).

## Configuration inheritance

GEB provides a complete set of baseline settings in [`reasonable_default_config.yml`](https://github.com/GEB-model/GEB/blob/main/geb/reasonable_default_config.yml). Model configurations inherit these baseline settings using `inherits`, and override only the parameters specific to the study area and experiment:

```yaml
inherits: "{GEB_PACKAGE_DIR}/reasonable_default_config.yml"

start_time: 2000-01-01
end_time: 2023-12-30
spinup_time: 1980-01-01

region:
  subbasin: 23011134
```

??? example "View complete baseline `reasonable_default_config.yml`"

